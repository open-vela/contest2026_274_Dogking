## 核心变化

**从“系统底座＋文字对话＋串口播报”，推进到“语音、视觉、表情与下位机统一编排的桌宠 v1.0 软件候选”。**

| 方向 | 初赛报告中的状态 | 后续新增／改进 |
| --- | --- | --- |
| 显示 | ST7735 画面颜色／竖条纹未收敛 | 正常色彩、LVGL 多表情与 Agent 联动；定位 SWOUT1 关闭导致旧版白屏并保留受控检查 |
| 录放音 | UART TW-TTS 可播，I2S 尚无可用 PCM 全链 | ICS43434 实录、MAX98357 实放、麦克风 x5 增益和音量；扬声器改走 I2S |
| ASR | 本地接口骨架／mock，语音输入未打通 | 通用 Zipformer 的 NPU 模型后端、跨块状态与流式特征；接入真实麦克风和常驻会话 |
| 本地 LLM | Qwen2.5-1.5B，冷读慢、跨请求缓存等待完善 | MiniCPM5-1B（约 688 MB）、RAM 常驻、有限上下文、KV 前缀／Q8 工作区和局部多核优化 |
| TTS | 主要依靠 UART 模块 | CPU 声学模型＋NPU vocoder 本地合成；完整短语排队、尾句／断流与英文未知词处理 |
| 交互 | 主要命令式演示 | 显式启动后持续等待、自动多轮、开头保留、协作停止和恢复；完善情绪风格与表情 |
| 视觉 | UVC 未打通，无完整相机识别入口 | 改走 Radxa 13M214 MIPI：RAW 采集、正常颜色、YOLO 六路输出、同帧 SPI 底图和框 |
| 识物 | 无真实语音识物业务闭环 | 语音触发新拍一帧，按实际 COCO 类别／数量播报，不让 LLM 猜图或复用旧框 |
| 路由 | 云优先＋本地 LLM 兜底 | 整套 ASR/LLM/TTS 的 online/local/auto；云前置失败可保留音频本地识别，动作／播出后不重放 |
| 云语音选择 | 初赛报告无多家云语音统一选型能力 | v218 保留火山，新增讯飞／腾讯原生 ASR/TTS、独立选择与加密配置；Edge 为可选电脑 HTTPS TTS 网关，非板端原生 |
| UFS | 未适配 | 受控 handoff、数据卷挂载、大文件复制／校验及模型读取；保留 SD 备用模型 |
| 下位机 | UART4 用于 TTS | 释放 UART4，以 115200 对接 STM32；严格动作规则、心跳／ACK、会话使能和失联撤权 |
| Bluetooth | HCI／Host 尚未适配 | 控制器查询、官方 H4／Host 扫描及启停生命周期；GATT／ESP32 双板业务继续保留待办 |
| 可恢复交付 | 已有构建／镜像机制 | 持续增加分段计时、故障注入、真实 ARM／ELF／镜像模型回读、独立摘要、Git bundle 和新目录恢复演练 |

本次 v1.0 复审还修正：**清理失败被取消／超时掩盖、动作分发前取消检查、前台 Ctrl+C 生命周期，以及策略文件丢失／损坏时默认本地**。

## 不重复计算的初赛成果

八核启动、4 GiB 分区内存、Wi-Fi、SSH/FTP/NTP、官方云 Agent、Qwen 和 VIP2 NPU／YOLO 执行能力在初赛报告中已经存在，不重新包装成“初赛后首次实现”。
真正新增重点在输入输出、模型效率、相机采集、真实业务编排和产品可靠性。

## 当前证据边界

后续 v218 已通过完整固件构建、13 个实际 ARM 编译单元、既有软件回归、签名对照及本机真实 TLS／HTTPS 处理测试。
提供商上游仍为 MOCK，尚无真实云凭据；Edge 合成／MP3 解码和板上声音未验收，也未生成新 SD 镜像。不能把新增接口称为“多家云语音均已实测通过”。
[扩展说明](CLOUD_VOICE_PROVIDERS_V218.md)、[封存软件证据](evidence/cloud-voice-v218/README.md)。

录放音、正常表情、相机出图、短时 YOLO／SPI、UFS 等有历史实机成果；新 v1.0 主要完成软件集成、故障回归、可烧写制品和恢复体系。
**新候选整机、云 ASR/TTS API、STM32 实际机械动作、长期稳定与 3–5 秒首音仍需统一验收。**
不宣称全 TTS 上 NPU、30 FPS 检测、AEC／播放中打断、MP4／完整 ISP／GPU、BLE 双板或 UFS 标称带宽已经完成。
