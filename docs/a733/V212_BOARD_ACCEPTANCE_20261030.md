## 对照旧通过版本及模块资料

与a733-i2s-v150-wav-5play-pass逐段对照，核心TX时钟、格式、映射和半字FIFO写法
没有发现足以确定本次无声的差异。v162录音/空闲PB7低电平修复仍保留，播放时已恢复mux3。
旧v150有声记录在录音后播放，CHCFG=11；v190冷TTS记录也存在CHCFG=1，
所以不能仅凭该差异直接宣判根因或盲改RX配置。

用户提供的厂家封装ZIP只包含模块外部符号/封装，不是内部电路原理图。
八脚依次为VCC/GND/LRCLK/BCLK/DIN/WS/SCK/SD；不能证明两组时钟已在板内短接。
原厂MAX98357A手册第16–19页说明数字接口/启动要求；配置上的48kHz、64fs与手册相容，
但配置值相容不等于模块实际收到这些信号。不调整电压、不把模块SD当作功放关断脚。

需要到达模块端的信号（断电检查接线，供电维持已验证方案）：

| A7Z物理针脚 | 模块功放端 | 模块麦克风端 |
| --- | --- | --- |
| 12 / PB5 | BCLK | SCK |
| 35 / PB6 | LRCLK | WS |
| 40 / PB7 | DIN | 不接SD |
| 38 / PB8 | 不接DIN | SD |
| 6 / GND | GND | 共地 |

这是信号应达到的对应关系，不是在没有内部原理图时断言板内未短接。

## 最小下一步，不再重复整机测试

先获取当前模块接线照片，重点看功放LRCLK/BCLK/DIN，不只看麦克风WS/SCK/SD。
可使用现有v212做32位发送的独立对照，无需重刷：

```text
echo tone32=1000,3000 > /dev/a733-audio
cat /dev/a733-audio
```

如仍无声，在模块端同时采LRCLK/BCLK/DIN，CH0/1/2依次对应，GND接公共地。
至少24MHz；用LRCLK上升沿触发，先arm再运行：

```text
echo tone=1000,3000 > /dev/a733-audio
```

保存播放期间10–40ms的原始.sr文件。预期LRCLK=48kHz、BCLK=3.072MHz、每半帧32位，
这些仍是待测值；检查DIN数据是否随1kHz正弦变化，不能只凭截图的密集竖线判断。
逻辑分析仪只接数字输入线，不能把功放差分喇叭输出当作地/逻辑输入。
得到波形后，再决定修复板端发送还是模块连接/功放输出，不再盲发新镜像。
