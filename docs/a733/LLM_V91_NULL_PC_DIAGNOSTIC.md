# v91：CPU7 空地址取指现场诊断

## v90 板端证据

用户上电日志确认：MPIDR `81000700`（CPU7 A76）、CurrentEL `4`（EL1）、ESR_EL1 `8600000d`、ELR_EL1/FAR_EL1 均为零，regs 位于 `42400150`。

ESR 的 EC 为 `0x21`（当前异常级指令取址异常），IFSC 为 `0x0d`（一级权限错误）。这表明地址零取指被 MMU 拒绝，不代表页表应当放开零地址执行。

v90 System.map 显示 CPU IDLE 栈数组从 `423f04a0` 开始，每核 8192 字节；CPU7 范围 `423fe4a0..424004a0`，异常帧位于该范围内。此证据指向 CPU7 启动/空闲任务附近的现场，不足以独立证明哪个函数有错。

## v91 变更与目的

保持 v89 的线程池代码和八核配置不变，异常入口先打印 LR_X30、SP、saved_ELR、SPSR，再打印 X00..X29。用于判断空调用的上一条指令、启动入口 X25 和返回帧状态。仅修改仓库 overlay，由既有构建脚本临时映射并恢复官方文件。

诊断不是根因修复。不要为了绕过现象禁用 A76、SMP 或给地址零执行权限。下一步将 LR 和保存的寄存器与本版本 ELF 反汇编对照，再实施针对性修复。
