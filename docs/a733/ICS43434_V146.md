## 断电接线检查（照片确认前不要盲目上电）

**厂商对合并模块 VCC 标注 DC 5V，但 ICS43434 裸 VDD 只能 1.65..3.63V。**
只按实际合并模块 VCC 接口供电；绝不能把 5V 直接接裸麦克风 VDD 或 A7Z GPIO。
先核对实际模块版本与正负极，必要时测模块麦克风端稳压后的电压。
所有数字信号是 3.3V 逻辑。麦克风未供电时不要向它持续输出时钟。

模块符号的 1..8 是**模块接口编号**，不是 A7Z 40-pin 编号：

| 模块接口 | A7Z 连接 | 方向/注意 |
| --- | --- | --- |
| 1 VCC | 核对模块后接 5V 电源，例如物理 pin2 | 仅合并模块 VCC；不是裸 VDD |
| 2 GND | GND，例如物理 pin6 | 共地，先核对极性 |
| 3 LRCLK | PB6 / 物理 pin35 | 主机输出至功放 |
| 4 BCLK | PB5 / 物理 pin12 | 主机输出至功放 |
| 5 DIN | PB7 / 物理 pin40 | 主机 DOUT0 → 功放输入 |
| 6 WS | PB6 / 物理 pin35 | 主机输出至麦克风，不假定与 LRCLK 板内短接 |
| 7 SCK | PB5 / 物理 pin12 | 主机输出至麦克风，不假定与 BCLK 板内短接 |
| 8 SD | PB8 / 物理 pin38 | 麦克风输出 → 主机 DIN0；不是 SD_MODE |

若断电通断测量确认两组时钟已板内相连，可避免重复线；否则两组都必须接。
不要把 DIN 和 SD 短接。LR 不在模块外部符号中，不猜它固定左/右，先录双声道。
扬声器跨接功放差分 OUT+/OUT-（模块插座），任一输出端都不能接地。
首轮降低音量/缩短 tone 时间；杜邦线尽量短（例如 <=10 cm），每组时钟旁带地，
远离功放输出与电源回路。该长度是布线建议，不是信号完整性保证。

## 实现与兼容边界

源码在比赛仓库的 A733 overlay；复用 openvela/NuttX 板级设备节点、互斥锁、
内核分配、系统时钟与文件接口，硬件寄存器按厂商 Linux BSP/芯片手册适配。
当前仍是 `/dev/a733-audio` 的轮询验收路径，不是已经接好官方音频框架或 DMA。
先证明新硬件录音，再接标准 I2S/audio lower-half、官方 Agent 云 ASR。

- ICS 模式固定 RX 双通道：CHCFG 的 RX_SLOT_NUM=1、RX_CHSEL=1、offset=1。
  RXMAP3=`00000100`（两个 byte），不是 TX 风格的 `00000010`。
- 始终接收左右两槽；`icsleft`/`icsright` 仅在软件选出目标槽，没有改变硬件为单槽。
  默认 `icscapture` 双声道、不混音、不自动挑 RMS 更大的槽，以免挑中串扰。
- 独立 ICS 文件，不覆盖 INMP441 旧录音。SR24、RXOM1，S24→S16 为算术右移 8。
- 采集先进入 RAM，停 RX 后写临时文件，检查所有写入与 close 后 rename 提交。
  超时/样本计数不符/过快/过慢/FIFO 错误不会替换上次成功文件。
- 每256个接收字检查总采集时限，另外每个等待保持100ms超时；异常慢时钟不能
  通过反复等“下一个字”把一次录音拖成几分钟。
- 双槽 5 秒：480000 个 FIFO 音频样本 + 9600 个 warmup word，
  target/consumed RX=489600，录制约5100 ms；WAV 内容恰好5秒，不含 warmup。
- 保存两路输出样本的总统计用于诊断；**总 RMS、非零、committed=1 都不是声学通过**。
- 旧 `capture/captureleft/captureright/capturecfg/capture32` 保持 INMP 文件路径与旧行为，
  每次显式重设完整 RX 配置，防止新旧模式泄漏。MAX98357 的 S16 tone 不改时钟/幅值。
- 不在 boot/init 自动启动流，不改 SMP/MMU/中断栈或 BLE 状态机，不做新硬件自动录制。

## 上板步骤

确认接线后使用 v146 候选，先保留 SD 的 `/data` 凭据/模型/录音。整盘烧录会覆盖卡上内容；
先备份重要数据。若熟悉仅替换内核流程，按已有交付工具验证内核哈希，不手改加载地址。

```sh
cat /dev/a733-audio
echo init > /dev/a733-audio
cat /dev/a733-audio
time "echo icscapture=5000 > /dev/a733-audio"
cat /dev/a733-audio
ls -l /data/ics43434-stereo.wav
```

录音时第1秒安静、第2..4秒说话、第5秒拍手；命令约5.1秒采集加写卡耗时。
默认 stereo WAV 应为 **960044字节，48kHz / 2ch / S16 / 5秒**。
先把此文件下载到电脑按左右声道试听/分析，不要先启动 ASR。
若一槽无声是可能的，但另一槽必须能辨识语音并随上述激励变化。

需要强制单路对照时：

```sh
time "echo icsleft=5000 > /dev/a733-audio"
cat /dev/a733-audio
time "echo icsright=5000 > /dev/a733-audio"
cat /dev/a733-audio
echo icsraw=1000 > /dev/a733-audio
cat /dev/a733-audio
```

输出 `/data/ics43434-left.wav`、`/data/ics43434-right.wav` 各480044字节；
`/data/ics43434-stereo-s24.bin` 为384000字节，48kHz左右交错、S24符号扩展为S32LE，
**不是有头 WAV，也不是打包的3字节 PCM**。
raw 的 target RX=105600、elapsed约1100ms。

下载 stereo WAV 后可在电脑用标准 Python 分离左右声道并导出逐100ms统计：

```sh
python tools/analyze-ics43434.py /path/to/ics43434-stereo.wav --output-dir /path/to/new-analysis --expected-seconds 5
```

输入录音保持只读；输出目录必须不存在，会生成 left.wav、right.wav、analysis.json、
windows-100ms.csv。恒值通道的 AC RMS=0 会单独体现，不把其未去直流 RMS 当成声音。
工具不会自动决定“麦克风通过”；仍须试听可辨识语音并核对已知安静/说话/拍手时段。

确认功放接线、避免麦克风/扬声器反馈后再独立回归播放：

```sh
echo tone=1000,500 > /dev/a733-audio
cat /dev/a733-audio
echo off > /dev/a733-audio
```

已初始化的 Agent/自动 TTS 可能同时发声，录音测试时保持安静，不开启持续播放。
当前不是全双工/回声消除路径。失败时先保留原始文件和完整 cat 报告；若传输计数正常但
仍仅噪声，下一步测 SCK/WS/SD 实际波形，而不是任意改位移/增益掩盖问题。
