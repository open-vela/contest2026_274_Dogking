# v1.0 软件审计与修正版交付

日期：2026-10-31；版本标识：`v217-audit2`。

## 1. 结论

本轮发现并修正了可复现的取消／所有权和配置失配问题，重新跑完软件回归、目标编译、完整链接及镜像校验。
审计后没有在本轮测试范围内复现软件阻断项，但**不能据此保证整机绝对无缺陷**。
没有新硬件、真实云 ASR/TTS API、机械动作或 3–5 秒声学首音验收。

## 2. 已修正的问题

| 项目 | 原风险 | 本轮修正与测试 |
| --- | --- | --- |
| 相机取消／超时后的清理 | 普通取消原因可能覆盖 `EOWNERDEAD`，后续尝试复用未知所有者的 NPU | `product_capture_outcome` 让所有权失败优先；实际 runtime 源测试取消后清理失败，禁止发布／播报旧结果 |
| 动作前的取消 | 语义分发边界缺少统一取消检查 | `ProductPorts::cancelled` 在分发前与输出前检查，取消后不发运动／不补发语音 |
| 前台 Ctrl+C | 前台返回／异常退出可能破坏仍需保留的任务生命周期 | SIGINT 协作 guard，安全退出后清 pending 并恢复 mask；隔离时保留 guard 和原任务 |
| 策略文件缺失／损坏 | 原默认 auto 可能违背用户本地使用意图 | 默认 local，仅完整 `auto`／`cloud` 文件启用对应模式；真实文件解析故障测试 |
| 固定临时配置残留 | 断电留下固定 `.tmp` 可能阻塞后续设置 | 每次使用唯一临时名；不把 FAT/VFS 替换夸大为断电事务 |

固件源码冻结：`8c5a7b3b267128b7859c37d1e1000ec9054732f4`。
修正主要位于 `product_core.*`、`product_runtime.cxx`；音频入口更新审计标识。
NPU 硬件执行函数、公开 ABI 和数值计算路径没有以“优化”为名被放宽。

- 最终镜像 EXT4／GPT／启动保护、49 项语音资产、MiniCPM5、YOLO 与测试 WAV 回读通过；Windows 独立 SHA256 与 sidecar 一致。

模拟引擎／设备测试明确不计作真实 NPU、声学、摄像头或云端验收。
