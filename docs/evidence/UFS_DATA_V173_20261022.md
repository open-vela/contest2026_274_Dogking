# UFS v173 软件、构建和镜像记录

## 实机边界

v172旧镜像受控scratch实机已通过，[原始证据](UFS_V172_RUNTIME_20261022.md)。
本轮没有连接SSH或写入物理设备，v173仍为文件系统候选，尚未验证真实format/mount、
模型文件或重启持久性。所有历史开发文件保留。

## 源码和主机验证

- `a733_ufs_data.c/.h`：完整生产core在ASan/UBSan下，4KiB/64KiB/1MiB、卷首/中/末
  精确写回读、171项故障、超范围/别名/型号/GPT/未资格拒绝、flush/保护区/隔离检查通过。
- v172生产scratch core和固定窗口编码器逐字不改，642故障回归通过。仅测试C增加
  fixture-only main开关，便于新data测试复用同一硬件模型。
- 驱动37场景通过；原reader221故障/19变异、readcheck3249故障、NOP463故障/17变异、
  quiesce454读故障+6写故障、handoff80、board65、link3357+577全部通过。
- 实际NSH函数体在稀疏普通文件上复现原32位截断；补丁后2GiB/4GiB/128GB
  skip/seek/verify和四处真实seek失败均通过。原source SHA-256
  `c4368cfab1e2f5b4a2442937e30209e0613bdf1732f14cb6cb870f601c77b181`，
  临时patched source `2e48f827a0a718759b4b1c8ed760c08cf8a6a9abc6d7dbefe3d0c4fbb70c1078`。
- 官方 `configfat.c/writefat.c` 原函数在/tmp稀疏普通文件验证30576479×4096B：
  FAT32、32扇区/cluster、每FAT934扇区、backup boot、FSINFO、两份FAT正确。
  这不是实际挂载证明。
- 音频应用/输出契约回归、SDK清理正常/拷贝失败/清理时信号3个fixture、项目恢复3个
  fixture通过。没有利用本轮UFS工作更改语音/NPU/显示/联网业务代码。

对应日志均在 `out/v173-*.log` 并随候选补充材料封存。

## 编译与反汇编

- GCC13.4.0，12个真实ARM64对象，最大栈帧不超过4096B；51个关键overlay源早晚
  暂存hash相同，另单独核对NSH实际patched hash。旧49关键源46个逐字不变，仅主UFS
  BSP、Kconfig和CMake新增入口；新data C/H不改原scratch/read传输。
- v173独立目录完整2982目标构建成功，九个显式实验开关；所有默认配置仍关闭新入口。
- NOP/read arena各77824B独立；bench65536B、scratch73936B、data状态144B
  都为互不重叠CPU BSS。新writer不增加DMA分配，runtime footprint37359616B。
- 最终ELF四处lseek之后均为 `tbz x0,#63`，不再是旧 `w0,#31`。
  地址分别40233868、40233930、40233974、40233a30；见linked disassembly日志。
- wrapper结束后由原生Windows Python检查170项SDK原件逐字恢复。
- SDK nuttx/apps现有.git条目无法解析，Windows/WSL均拒绝；不修复/改写SDK Git元数据，
  不虚构其commit。以实际配置、primary-source hash、overlay归档和二进制hash固定本轮。

## 镜像和恢复

镜像、内核、源码hash见 [ARTIFACTS](../ARTIFACTS.md)。基于不变的v172镜像，仅替换
SD分区3内核；ext4只读检查、提取内核hash、GPT和2GiB大小检查通过。继承基线分区4
未对齐2048扇区提示，不在本轮重写GPT。另原生比较SD分区3之外2025848832B，
与v172基线完全一致；源码461文件逐字核对，旧454源路径无删除，444个不变、10个
修改、7个新增。源归档保留dirty working bytes，而非只记录HEAD。

完整项目checkpoint保留docs、开发过程、dirty patch、原index及Git历史，外部镜像/资产
作为hash引用；恢复演练只写NEW out目录，不覆盖原工作树或SDK。最终封存门禁在
`out/v173-final-integrity.json`，其缺失/非成功时不能宣称完整交付门禁已完成。

测试流程：[UFS_DATA_V173](../a733/UFS_DATA_V173.md)。先资格检查再显式data-rw；
只有首次创建FAT会清空第三分区测试Linux，之后重启只挂载，不重做mkfatfs。
