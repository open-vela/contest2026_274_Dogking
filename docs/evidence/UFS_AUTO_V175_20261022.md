# UFS v175 软件、交付与基线证据

2026-10-22 开始，跨至10月23日整理。v174用户板测通过后追加，历史封存不改。

v175加入独立开机任务，验证已限定Kingston现有FAT32卷后挂载/ufs；持久自启动开关；
Agent自动优先已通过v174模型，旧默认路径自动迁移语义但不改配置文件，保留强制SD/
自定义路径。读取大小/头部不是每次开机全SHA。不会开机mkfatfs/测试写入/删旧文件。

软件证据目录/日志在项目out下：

- `v175-auto-host-r2.log`：真实boot状态机七步失败、mount EBUSY拒绝、幂等、后台、
  卸载/重挂载、spawn失败与模型选择矩阵，ASan/UBSan通过；不是真实mount/HCI。
- `v175-data-host-r2.log`：原171个数据层故障注入及现有FAT主备份/FSINFO限定通过；
  限定时零媒体WRITE、一次CACHE10；底层writer packet与IO主体对v174逐字节不变。
- `v175-fat-host-final.log`：实际SDK mkfatfs规划/写入临时稀疏普通文件，4K块、
  30576479扇区/FAT32元数据/备份一致及畸形输入拒绝。
- `v175-driver-host.log` / link、board、handoff、quiesce、nop、readcheck、scratch
  regression：原有故障分支、642个scratch故障以及暂存fixture保持通过。
- `v175-dd-host-final-r2.log`：SDK恢复后，真实NSH dd补丁对2GiB/4GiB/128GB seek与
  真错误路径通过；首个final日志因命令文件名笔误失败保留，不冒称成功。
- `v175-audio-regression.log` / `v175-route-regression.log`：原音频/路由软件契约通过；
  模拟PCM，不增加语音硬件/ASR全链路完成声明。
- `ufs-v175-arm-final/summary.json`：12个真实驱动/板级ARM64对象，最大栈均<=4096。
- `storage-v175-arm/summary.json`：真实bulk主程序，最大栈1536B。
- `storage-integration-v175-arm-r2/summary.json`：boot/Agent/services/config四单元，
  最大栈112/2112/80/464B。首轮boot缩进告警失败已修复，新目录r2通过。
- `build-v175-ufs-auto.log`：2985目标完整整机成功；Rust缺可选LLVM参数警告保留，
  不启用Rust功能。linked符号与57关键源/6应用源早晚暂存一致。
- `sdk-restored-v175-final.log`：原SDK173路径字节级恢复通过，不依赖覆写官方目录。
- `v175-source-chain-final.json`、layout/verify/package/seal/native-integrity与最终
  checkpoint/recovery日志构成交付链；最后以`v175-final-integrity.json`为准。
