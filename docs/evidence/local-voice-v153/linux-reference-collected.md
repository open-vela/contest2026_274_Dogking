## 用户听音确认

用户原话“音频内容完全正确”，两段WAV均确认，不是分析工具自行推定清晰度。
22050Hz单声道S16：“你好”17920样本/35884字节，约0.813秒；
“测试成功”29440样本/58924字节，约1.335秒。音频无放大，安全衰减系数1。
两段原始NPU FP32输出SHA见主文档。mel静音底值也输出稳定，但不把它作为语义通过。
声学模型在开发主机CPU，声码器在Linux A733 NPU；未做openvela全链路认证。
