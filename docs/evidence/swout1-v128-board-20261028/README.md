# SWOUT1 单变量手动使能：显示恢复

用户报告：旧通过 v128 和 v199 均白屏；更换线材无效。
SPI-1 公共地悬空，不能作为板端信号结论。通道映射纠正为
CH0=SCL、CH1=SDA、CH2=RST、CH3=DC、CH4=CS；不能再把 CH2 当 CS、CH4 当 RST。
SPI-2 有 960 次 DC 跳变，但 SCL/SDA 为低、CS 为低、RST 为高。
SPI-3 仅2.08秒且包括 DC 在内全部无跳变，不能证明覆盖了写屏时段。
原始分析仪文件仍保留在工作区 SPI测试，不删除、不篡改。

按厂商 AXP8191 驱动：0x11 bit3=dc1sw1，bit4=dc1sw2，0x12 是 DCDC1 电压配置。
0x11=17 表示 SWOUT1 关闭、SWOUT2 开启；0x12=17 对应3.3V配置，非实测电压。
V1.11 原理图 GPIO 页中，SoC PD 供电脚经 R251 接 VCC33-LCD，电源页对应 SWOUT1。
不能只凭电源页 VCC-PD 标注，将 SPI 所在 PD 引脚直接认作 BLDO2 的1.8V支路；
前期该条推测已撤回，禁止据此改 BLDO2 或给内部供电域外接3.3V。

用户只进行17->1f控制位改变，电压配置仍17；同一次 SD 启动后实体屏恢复三色块，
LVGL test10与七种demo表情全部正常。[摘录](user-excerpt.txt)保留用户原始措辞。
这支持“本次关闭的 SWOUT1 是显示失效直接原因”。具体是谁、在哪段引导流程关闭它，
尚未确定；不能说已经证明 UFS 驱动抢占 SPI 或确认焊接损坏。

状态：v128 + 手动开启 SWOUT1 的显示硬件复测通过；不是 v199 RAW 或 v200 自动脚本通过。
v128 文件大小匹配，但本次板上没有 CRC/SHA，不能宣称独立核验了精确二进制身份。
后续保护脚本仅接受同型号/版本、DCDC1全开配置ff、电压配置17、控制17或1f。
