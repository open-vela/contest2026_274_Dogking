# VIP2 lessons: non-portable case study

- Validate identity, MMU pool, ABI, self-test, and tiny LeNet before large networks.
- Vendor Linux model metadata, timing, raw outputs, CRCs, and traces provide golden evidence.
- Prepared packages can bridge proprietary networks but are not a generic compiler/loader.
- Exact LeNet CRC matching establishes a deterministic baseline.
- YOLOv5/v8 require every head, exact tensor sizes, and correct postprocessing; completion alone is not detection success.
- Dynamic inputs prove the runtime is not replaying output.
- Expose identity, buffer/page usage, task counts, IRQ/idle, staged input/model, and last error.
- Do not infer LLM support from hardware capability; absent compiler/runtime/KV support justifies CPU-first execution behind a future NPU interface.
